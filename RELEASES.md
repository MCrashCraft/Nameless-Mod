# Downloads

Download **NamelessMC 0.2.0** for your server’s exact Minecraft release and mod loader. Install one NamelessMC JAR in the server’s `mods` folder. Players do not need the mod.

Each release includes the mod JAR, complete corresponding GPL source and a SHA-256 checksum file. For Quilt, use the Fabric-compatible JAR supplied on the Quilt release page; its filename remains unchanged. Fabric and Quilt also require the matching Fabric API specified on the release page.

**Prerelease** marks a selected beta NeoForge loader or a documented Forge shutdown limitation. Read that release’s notes before installation. Forge has no published loader for Minecraft 1.20.5 or 1.21.2.

## Installation and configuration

Follow the [installation instructions](README.md#installation), then configure the website connection privately in `config/namelessforge/main.yaml`. Website features require the corresponding NamelessMC modules and settings.

## Validation

All 67 distinct native artifacts passed 46 tests and their package audits. Separate exact-loader checks recorded 88 clean startup, command, reload and shutdown results across 90 published combinations. Forge 1.21 and 1.21.9 have reproduced configuration-watcher shutdown limitations and are published as prereleases.

See the [validation matrix](compatibility/VALIDATION.md), [known loader limitations](compatibility/KNOWN-ISSUES.md) and [license](LICENSE). Local checks do not certify real website transactions or every other installed mod.
